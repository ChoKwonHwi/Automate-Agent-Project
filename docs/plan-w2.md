# W2 계획 — 임베딩 · 검색 · 평가 기준선

> PRD 11장 W2: "인덱싱 + 기본 RAG + Golden Set 100개 + LLM 3종 비교"
> 완료 기준: 출처 인용 답변이 동작하고, **베이스라인 지표**(Recall@5, MRR, 인용 정확도, 거절률)가 측정되어 있으며, 최종 LLM이 정해져 있다.
> 하이브리드 검색 · Reranker 는 W3 범위다. W2는 "개선 전 기준선"을 만드는 주간이다.

## 1. 설계 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 벡터DB | **Qdrant 로컬 모드** (`qdrant-client`, 파일 저장, Docker 불필요) | 청크 ~1천 개 규모에 충분. W6에 Docker 서버 모드로 전환 (코드 동일) |
| 임베딩 | **BGE-M3 dense** (1024차원, fp16, GPU) | 한국어 성능, 8K 토큰 입력. 같은 모델의 sparse 출력은 W3 하이브리드에 재사용 가능 |
| 임베딩 대상 | 청크의 `embed_text` (`[기관] 규정 > 장 > 조(제목)` + 본문) | 청크만 봐도 출처를 아는 컨텍스트 헤더 |
| 저장 payload | chunk 메타데이터 전체 (org, doc_title, category, section, article_label, effective_date, source_url …) | 필터 검색 · 출처 인용에 사용 |
| ID | `chunk_id` 의 UUID5 | 재인덱싱 시 같은 청크는 덮어쓰기 (멱등) |
| 증분 인덱싱 | 본문 해시가 같으면 재임베딩 생략 | 규정 1개 추가 시 전체 재계산 방지 |
| VRAM | 인덱싱 중에는 Ollama 모델 언로드 (`keep_alive=0`) | 8GB 예산 (PRD 8.3) |
| 거리 | Cosine | BGE-M3 권장 |

## 3. Golden Set 작성 가이드

파일: `data/eval/golden_set.csv` (엑셀 편집 가능, **CSV UTF-8** 로 저장, 저장소에 커밋)

| 컬럼 | 설명 | 예 |
|---|---|---|
| id | q001 ~ q100 | q001 |
| type | `fact` 사실 / `numeric` 표·수치 / `multi` 여러 조항 종합 / `refuse` 근거 없음 | numeric |
| category | sources.csv 의 분류 | 여비 |
| question | 직원이 실제로 물을 법한 말투로 | 서울로 출장 가면 숙박비 얼마까지 돼? |
| answer | 규정 원문 기준 정답 (짧게) | 부서장 이하는 1박 10만원 상한 (실비) |
| evidence | 근거 조항, 여러 개면 `;` 로 구분 (`refuse` 는 비움) | 여비규정 별표1; 여비규정 제16조 |
| notes | 메모 (선택) | 이사장·임원은 상한 없이 실비 |

**구성 (100문항)**

| type | 개수 | 작성 요령 |
|---|---|---|
| fact | 50 | 조문 하나로 답이 나오는 질문. 규정 용어 대신 일상어로 ("특별휴가" → "결혼하면 며칠 쉬어?") |
| numeric | 20 | 별표 금액 · 일수 · 기간 (여비 별표, 행동강령 가액, 민원 처리기간 등) |
| multi | 15 | 두 조항 이상 필요 ("공단 차 타고 출장 가면 일비는?" → 제16조 ③ + 별표1) |
| refuse | 15 | 규정에 없는 것 ("주식 투자 추천해줘", "다른 회사 연봉은?") + **그럴듯하지만 규정에 없는 것** ("재택근무 신청 절차는?" — 실제로 없는지 확인) |

**분류 배분 (refuse 제외 85문항)**: 여비 18 · 복무(취업규정) 15 · 보수/복지 12 · 인사/교육 10 · 윤리(행동강령) 10 · 결재(위임전결) 8 · 회계/계약 7 · 감사/경영/민원 5

**원칙**
- 반드시 규정 원문을 보고 사람이 작성한다 (LLM 생성 금지 — PRD 7.3).
- 검색 결과를 보고 질문을 만들지 않는다 (검색에 유리한 질문으로 편향됨). 원문 → 질문 순서로.
- 같은 조항에서 3문항 이상 만들지 않는다.

## 4. 평가 지표 (W2 기준선, PRD 10장 목표는 W3 이후)

| 지표 | 계산 | W2 기대치 | 최종 목표 |
|---|---|---|---|
| Recall@5 | 근거 조항 중 하나라도 top-5 안에 있는 문항 비율 | 측정만 | ≥ 0.85 |
| MRR | 첫 정답 순위의 역수 평균 | 측정만 | ≥ 0.70 |
| 인용 정확도 | 답변이 인용한 조항 ⊂ 근거 조항 | 측정만 | ≥ 90% |
| 거절률 | refuse 문항 중 정확히 거절한 비율 | 측정만 | ≥ 90% |
| 수치 정답률 | numeric 문항 중 금액·일수가 정확한 비율 | 측정만 | 100% (W4 계산 도구 포함) |
| 지연 | 검색 / 생성 p50 · p95 | 측정만 | p95 ≤ 10초 |

평가 단위는 `chunk_id` 가 아니라 **`규정명 + 조번호`** (분할 조각 중 어느 것이 걸려도 정답) — 재청킹해도 Golden Set 이 깨지지 않게.
