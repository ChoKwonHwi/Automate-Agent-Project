# 데이터 수집 기준

이 프로젝트는 합성(생성형) 데이터를 사용하지 않고, 공개된 실제 문서만 사용한다.

## 1. 규정 코퍼스

### 수집처
1. **(권장) [국가법령정보센터](https://www.law.go.kr) → 그밖의 정보 → 공공기관 정관/규정**
   - 법제처가 공공기관 규정을 한곳에 모아 둔 메뉴. 기관명이나 규정명(예: "여비규정")으로 검색한다.
   - 규정 화면의 저장 기능으로 PDF(또는 HWP)를 받는다. 기관이 달라도 문서 형식이 같아 파싱이 안정적이다.
   - 같은 데이터를 국가법령정보 Open API("학칙·공단" 분류)로도 받을 수 있다 — OC 승인 후 자동 수집에 사용.
2. 각 기관 홈페이지: 경영공시(또는 정보공개) → "내부규정" / "사규" 메뉴
3. [ALIO](https://www.alio.go.kr): 내부규정은 기관별 **수시공시 게시판** 항목이다.
   `기관명_2026년_1분기.pdf` 같은 분기 공시 파일(임직원 수, 복리후생비 등)은 통계표라서 **사용하지 않는다.**

> 판별법: 첫 쪽에 "제1조(목적) 이 규정은…" 이 있고 끝에 "부칙" 이 있으면 규정 문서다.

### 기관 선정 기준
주 기관 1곳 + 보조 기관 2곳. 아래 5개 분류가 모두 공개된 기관을 우선한다.

| category 값 | 규정 예시 | 사용 시나리오 |
|---|---|---|
| 여비 | 여비규정 (별표 금액표 포함) | 출장비 계산, 신청서 초안 |
| 복무 | 복무규정, 취업규칙 | 휴가 · 근무시간 질의 |
| 보수 | 보수규정 | 수당 질의 |
| 회계 | 회계규정, 경비 집행 지침 | 경비 규정 준수 검사 (Phase 2) |
| 인사 | 인사규정 | 일반 질의 |

- 파일 형식은 PDF > HWPX > HWP 순으로 선호한다. 스캔본(이미지 PDF)은 피한다.
- 시행일(최종 개정일)이 확인되는 문서를 고른다.

### 저장 규칙
```
data/raw/{org_code}/{규정명}.{pdf|hwpx|hwp}
```

### data/sources.csv 컬럼
| 컬럼 | 필수 | 설명 | 예시 |
|---|---|---|---|
| org | O | 기관명 | 한국○○공사 |
| org_code | O | 영문 약칭 (폴더명과 동일) | kxx |
| title | O | 규정명 | 여비규정 |
| category | O | 여비 / 복무 / 보수 / 회계 / 인사 / 기타 | 여비 |
| effective_date | O | 시행일 (YYYY-MM-DD) | 2025-03-01 |
| source_url | O | 다운로드한 페이지 URL | https://... |
| collected_at | O | 수집일 (YYYY-MM-DD) | 2026-10-20 |
| file_path | O | 프로젝트 루트 기준 경로 | data/raw/kxx/여비규정.pdf |
| doc_id | | 비우면 `{org_code}-{파일명}` 으로 자동 생성 | |
| notes | | 메모 | 별표 2개 포함 |

엑셀로 편집할 때는 **"CSV UTF-8(쉼표로 분리)"** 형식으로 저장한다.

## 2. 상위 법령
- [국가법령정보 공동활용 Open API](https://open.law.go.kr): 근로기준법 등 규정이 참조하는 법령 원문
- 승인 후 발급되는 `OC` 값을 `.env` 의 `LAW_API_OC` 에 넣는다.

## 3. 평가 데이터
- 수집한 규정 원문을 보고 사람이 직접 질문 · 정답 · 근거조항을 작성한다 (최소 100개).
- 보조 자료: [AI Hub](https://www.aihub.or.kr) 행정 문서 대상 기계독해 데이터. **재배포 금지이므로 저장소에 포함하지 않는다.**
